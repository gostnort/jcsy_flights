# JCSY 航班自动查询工具0.6

## 简介

本脚本是一个为 **Tampermonkey (油猴)** 设计的用户脚本，旨在自动化查询 JCSY 格式文本中的航班到达时间。

它会在 Google 搜索页面注入一个操作面板，用户粘贴 JCSY 文本后，脚本会自动逐一查询每个航班，并将查询到的到达时间回填到原始文本的 `ARVL` 列，同时保持格式完美对齐，方便用户直接复制使用。

## 功能特性

- **自动化查询**: 自动从 JCSY 文本中提取航班号并在 Google 进行搜索。
- **无缝集成**: 在 `google.com` 页面右下角显示一个简洁的操作界面。
- **格式对齐**: 填充航班到达时间，确保 `ARVL` 列下的所有内容对齐。
- **结果回填**: 将查询结果（如到达时间、`未能找到`、`日期不符`等）直接插入到原始文本中。
- **灵活控制**: 提供“停止”按钮以中断查询并输出部分结果，提供“关闭”按钮以隐藏界面。

## 安装与使用

1.  **安装 Tampermonkey**:
    首先，你需要在你的浏览器（如 Chrome, Firefox, Edge）中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。

2.  **开启开发者模式**:
    安装完成后，请进入 Tampermonkey 的扩展管理页面或设置，**确保“开发者模式”已经开启**。这是加载和调试本地脚本所必需的。

3.  **安装脚本**:
    - 打开 Tampermonkey 的管理面板。
    - 点击“添加新脚本”标签页。
    - 将 `JCSY_flight_query.js` 文件的全部内容复制并粘贴到编辑器中。
    - 保存脚本（文件 -> 保存）。

4.  **使用脚本**:
    - 访问任意 **`https://www.google.com`** 页面。脚本窗口仅在此域名下显示。
    - 页面的右下角会出现“JCSY 航班查询”窗口。
    - 将你的 JCSY 文本完整地粘贴到输入框中。
    - 点击“开始查询”按钮。
    - 脚本会开始自动查询，页面会进行多次跳转。你可以随时点击“停止”按钮来中断查询并立即查看已获取的结果。
    - 查询完成后，页面将返回至原始的 Google 页面，输入框内会显示已填好到达时间的最终结果。
    - 你可以点击窗口右上角的 `×` 按钮来随时关闭操作窗口。

## 注意事项

- **目标城市配置**: 脚本默认的目标城市是 `Los Angeles`。如果需要查询抵达其他城市的航班，请修改脚本文件中的 `DESTINATION_CITY` 常量。
- **页面跳转**: 查询过程中会涉及多次页面跳转，这是正常现象。
- **显示范围**: 本脚本的操作窗口 **仅会** 在 `google.com` 域名下的页面显示。
